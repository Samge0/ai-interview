常见问题

关于部署、配置和使用的常见疑问解答

需要什么技术栈来部署这个应用？
Docker 部署需要 Docker 和 Docker Compose。源码部署需要 Python 3.12+ 和 uv 包管理器。推荐使用 Docker 部署，更简单且环境隔离。
如何配置不同的 LLM 提供商？
在 .env 文件中设置 OPENAI_BASE_URL 为对应的 API 地址，OPENAI_API_KEY 为你的密钥。支持所有 OpenAI 兼容的提供商，如 Azure OpenAI、Anthropic Claude 等。
访谈记录存储在哪里？
所有访谈记录自动保存到 output 目录，以 JSON 格式存储。每个访谈会话生成独立的文件，便于备份和分析。
如何启用图片生成功能？
在 .env 文件中配置 IMAGE_API_KEY、IMAGE_API_BASE_URL 和 IMAGE_API_MODEL。支持 DALL·E、Imagen、Gemini 等多种图片生成服务。
访问口令是必须的吗？
不是必须的。如果将 ACCESS_CODE 留空，则不会启用访问验证。但对于公网部署，强烈建议设置访问口令以保护应用安全。
